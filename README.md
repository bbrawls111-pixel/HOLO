# Holo — Private Game Development Workspace

Закрытое рабочее пространство для двух разработчиков: общение, общее хранилище ресурсов,
история версий и ИИ-сессии в одном Electron-приложении.

```
Holo/
├── server/   Node.js: REST + WebSocket, SQLite (node:sqlite), файлы на диске
└── client/   Electron + React + TypeScript + CSS Modules (Vite)
```

## Что уже работает (ядро, этап 1)

- **Вход** — два заранее созданных аккаунта, регистрация закрыта.
- **Ник и аватар** — выбираются при первом входе, меняются в «Настройках»
  (своё фото с обрезкой до квадрата или цветной аватар с инициалами).
- **Онлайн-статус** — при входе клиент шлёт `POST /api/presence/online`, сервер показывает «онлайн».
  Клиент повторяет запрос раз в 5 минут; сервер раз в 5 минут снимает статус с тех, кто не отметился.
  При закрытии приложения статус снимается сразу (`/api/presence/offline`).
- **Синхронизация** — событийная модель: действие = один HTTP-запрос, сервер пишет событие в журнал
  и рассылает его по WebSocket. После обрыва связи клиент догружает пропущенные события.
- **Ресурсы** — drag & drop файлов и папок, дерево, поиск, превью (картинки, аудио, видео, текст, шрифты),
  версии с восстановлением, комментарии, переименование и перемещение.
- **Чат** — каналы, вложения, вставка скриншотов, правка и удаление своих сообщений, уведомления.
- **ИИ** — ChatGPT / Gemini / Claude во встроенных страницах; сессии с изолированными
  `persist:`-разделами по номеру аккаунта.
- **Счётчик операций** — сервер считает запросы за месяц против лимита 500 000.

Графики, структуры и документация — следующий этап.

## Запуск

Нужен Node.js 22.13+.

```powershell
cd server
npm install
npm run create-user -- <логин1> <пароль1>
npm run create-user -- <логин2> <пароль2>
npm start            # http://0.0.0.0:4000
```

```powershell
cd client
npm install
npm run dev          # Vite + Electron
```

При входе укажите адрес сервера (по умолчанию `http://localhost:4000`).

Переменные сервера: `HOLO_PORT`, `HOLO_HOST`, `HOLO_DATA_DIR`, `HOLO_OPS_LIMIT`, `HOLO_MAX_UPLOAD`.

## Экономия запросов

- WebSocket только принимает события, клиент ничего по нему не шлёт.
- Все запросы идут из главного процесса Electron, без CORS-префлайтов.
- При старте весь проект грузится одним запросом `/api/bootstrap`.
- Присутствие стоит 1 запрос в 5 минут, то есть около 290 в сутки на человека.
